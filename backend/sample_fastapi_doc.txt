FastAPI is a modern, fast (high-performance), web framework for building APIs with Python 3.8+ based on standard Python type hints. The key features are: Fast to code, Fewer bugs, Intuitive, Easy, Short, Robust, and Standards-based. FastAPI relies on Pydantic for data validation and Starlette for tooling.
